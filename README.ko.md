# iCloud+ ‘나의 이메일 가리기’ 생성 및 복사

[日本語](README.md) | [English](README.en.md) | [简体中文](README.zh-CN.md)

현재 사이트 이름을 레이블로 사용해 iCloud+의 ‘나의 이메일 가리기’(Hide My Email) 주소를 만들고 클립보드에 복사하는 Chrome 확장 프로그램입니다. Manifest V3를 지원합니다.

- 확장 프로그램에서 **두 번 클릭**하면 됩니다(도구 모음 아이콘 → ‘만들고 복사’). 생성에 성공하면 팝업이 주소를 자동으로 복사합니다.
- 일반 생성 시 iCloud 탭을 앞으로 가져오지 않습니다. 기존 iCloud 탭을 백그라운드에서 재사용하고, 없으면 비활성 탭으로 엽니다.
- 더블 클릭이나 가벼운 재시도로 같은 주소가 중복 생성되지 않도록 막습니다.
- 비밀번호나 인증 코드를 다루지 않습니다. Apple 로그인 화면에서 직접 로그인합니다.
- 만든 주소를 외부 서비스로 전송하지 않습니다. 주소는 브라우저 세션에만 보관합니다.

## 필요한 것

1. Google Chrome 120 이상
2. iCloud+ 구독(개인 또는 가족 공유)
3. Apple Account의 2단계 인증
4. 평소 사용하는 Chrome 프로필에서 iCloud에 로그인할 수 있어야 함

생성에는 2단계 인증이 필요합니다. iCloud+에 가입되어 있어도 iCloud.com에 ‘나의 이메일 가리기’가 표시되지 않으면 웹 전용 접근 등 Apple의 제한이 적용될 수 있습니다.

## 설치

이 저장소에는 바로 불러올 수 있는 `dist/`가 포함되어 있습니다. 빌드는 필요하지 않습니다.

[GitHub Releases](https://github.com/spa77k/icloud-hide-my-email-extension/releases)의 배포 zip을 사용하는 경우 zip을 풀고 4단계에서 압축을 푼 폴더를 선택합니다.

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 오른쪽 위의 ‘개발자 모드’를 켭니다.
3. ‘압축해제된 확장 프로그램을 로드합니다’를 클릭합니다.
4. 이 프로젝트의 `dist` 폴더를 선택합니다.
5. 확장 프로그램 메뉴에서 ‘iCloud+ 나의 이메일 가리기 생성 및 복사’를 고정합니다.

소스에서 다시 빌드하려면:

```bash
npm install
npm run build
```

`dist/`가 갱신됩니다. `chrome://extensions`에서 확장 프로그램을 다시 로드하면 반영됩니다.

## 사용 방법

1. 이메일 주소를 입력할 사이트를 엽니다.
2. 도구 모음의 확장 프로그램 아이콘을 클릭합니다.
3. 레이블을 확인합니다. 현재 탭의 호스트 이름(예: `example.com`)이 자동으로 입력됩니다. 필요하면 수정합니다.
4. ‘만들고 복사’를 클릭합니다. 현재 사이트와 팝업은 전환되지 않습니다.
5. 처음에는 Apple 로그인이 필요할 수 있습니다. 팝업의 ‘iCloud 열기’를 누르면 iCloud 탭이 앞으로 나옵니다. 거기에서 로그인한 뒤 팝업으로 돌아와 다시 ‘만들고 복사’를 누릅니다.
6. 주소가 만들어지면 팝업에 표시되고 자동으로 클립보드에 복사됩니다. 복사되지 않았다면 ‘복사’를 누릅니다.

iCloud 탭은 백그라운드에 열린 상태로 남습니다. 확인하려면 팝업의 ‘iCloud에서 확인’을 사용합니다.

### 팝업을 닫은 경우

생성 중에 팝업을 닫아도 작업은 취소되지 않습니다. 완료 후 팝업을 다시 열면 결과가 표시되고 그대로 복사할 수 있습니다.

### 클릭 수와 시간

- 확장 프로그램 조작: **두 번 클릭**(아이콘, 생성 버튼). 자동 복사에 성공하면 복사 조작이 필요 없습니다.
- 실제 iCloud+ 계정에서의 생성 시간은 측정하지 않았습니다. 네트워크와 iCloud 응답에 따라 달라집니다.

## 작동 방식

Apple의 공개 API가 아니라 iCloud.com의 공식 웹 화면을 확장 프로그램이 조작합니다.

1. `icloud.com/icloudplus` 탭을 백그라운드에 준비합니다(기존 탭 재사용, 없으면 비활성으로 열기).
2. ‘나의 이메일 가리기’를 엽니다.
3. 새 주소 만들기 화면을 엽니다.
4. 레이블을 입력합니다.
5. ‘이메일 주소 생성’을 누릅니다.
6. 생성 화면의 후보 주소와 확인 후 결과(목록 항목의 레이블 제목＋주소, 또는 생성된 주소 상세 화면의 나의 이메일 가리기 필드)를 대조해 이번에 만든 주소만 읽고, 포커스가 있는 팝업에서 클립보드로 복사합니다.

후보 주소는 생성 대화상자 안에서만 읽습니다. 전달 주소, 계정 이메일, 기존 목록, 메모 필드, 숨겨진 주소는 후보나 결과로 사용하지 않습니다. 확인 후에는 보관한 후보와 일치하고, 이번 레이블 제목이 정확히 같은 목록 항목이거나 생성된 주소 상세 화면에 나의 이메일 가리기 필드가 확인된 경우에만 성공으로 처리합니다. 후보를 하나로 특정할 수 없거나, 확인 시 후보가 바뀌었거나, 일치하는 결과를 확인할 수 없으면 ‘확인되지 않음’으로 멈추고 복사하지 않습니다.

백그라운드 탭에서는 Clipboard API를 사용하지 못할 수 있으므로 복사는 팝업에서 수행합니다. 확인 전에 표시되는 후보 주소는 복사하지 않고, 확인된 주소만 복사합니다.

확장 프로그램은 비공개 API를 직접 호출하지 않습니다. 다만 iCloud.com의 화면 DOM과 내부 화면 전환에 의존합니다. Apple이 이 흐름을 위한 공식 확장 프로그램 API를 제공하지 않으므로 화면이 바뀌면 작동하지 않을 수 있습니다.

## 지원 언어

확장 프로그램의 사용자 UI는 다음 네 가지 언어를 지원합니다.

- 일본어
- 영어
- 중국어(간체)
- 한국어

UI는 Chrome의 UI 언어에 맞춰 자동으로 전환됩니다. iCloud.com 화면 조작도 Apple 공식 도움말에서 확인한 일본어, 영어, 중국어(간체), 한국어의 주요 문구를 지원합니다. 실제 로그인된 iCloud+ 계정에서의 주소 생성은 언어와 관계없이 확인하지 않았으며, 중국어와 한국어 iCloud.com 실제 화면도 실제 브라우저에서 확인하지 않았습니다. 레이블 대조 자체는 언어와 무관하며, 입력한 레이블과 iCloud의 제목을 정확히 일치하는지 비교합니다.

## 제한과 미확인 사항

- Apple의 공개 문서에는 임의의 나의 이메일 가리기 주소를 만드는 엔드포인트가 없는 것으로 보입니다. 이 확장 프로그램은 웹 화면 조작으로 주소를 만듭니다.
- iCloud+ 구독과 2단계 인증이 필요합니다. 같은 Apple Account로 iCloud.com에 로그인되어 있어야 합니다.
- 지원하는 iCloud 호스트는 `www.icloud.com`입니다. Apple이 화면을 다른 호스트(예: beta)로 옮기면 작동하지 않습니다.
- iCloud UI 자동화는 Apple 공식 도움말의 일본어, 영어, 중국어(간체), 한국어 주요 문구를 대상으로 합니다. 중국어와 한국어의 실제 iCloud.com 화면은 확인하지 않았으며 문구가 바뀌면 작동하지 않을 수 있습니다.
- 레이블 길이, 사용 가능 문자, 만들 수 있는 주소 수는 Apple의 기준을 따릅니다. 확장 프로그램이 자체적으로 상한을 판정하지 않습니다.
- 일반 생성 시 iCloud 탭은 백그라운드에 유지됩니다. 사용자가 ‘iCloud 열기’를 눌렀을 때만 앞으로 나옵니다.
- 자동 복사는 팝업에서만 수행합니다. iCloud 탭(백그라운드 문서)에서는 복사하지 않습니다. 팝업을 닫았다면 완료 후 다시 열어 결과를 확인하고 복사하세요.
- Service Worker가 중지되는 경우에 대비해 작업 상태를 `chrome.storage.session`에 저장합니다. 생성 중에 중단되면 ‘확인되지 않음’으로 멈추고 자동으로 재시도하지 않습니다.
- 생성 결과를 확인할 수 없으면 중복 생성을 막기 위해 ‘확인되지 않음’으로 멈춥니다. iCloud에서 결과를 확인하고 확인란을 선택한 뒤 재개하세요.
- **실제 로그인된 iCloud+ 계정에서의 주소 생성은 확인하지 않았습니다.** 검증은 단위 테스트와 로컬 모의 iCloud 화면을 사용한 Chrome E2E가 중심입니다. 실제 계정에서 사용할 경우 Apple의 공식 화면에서도 결과를 확인하세요.
- 이 확장 프로그램은 Apple 제품이 아니며 Apple의 약관이나 지원 대상이 아닙니다.
- 이 확장 프로그램은 비공식 도구이며 Apple과 관련이 없습니다.

## 권한

| 권한 | 용도 |
| --- | --- |
| `storage` | 작업 상태와 결과를 `chrome.storage.session`에 임시 저장 |
| `activeTab` | 팝업을 열 때만 현재 탭의 URL과 제목을 레이블 제안으로 사용 |
| `clipboardWrite` | 만든 주소를 클립보드에 복사 |
| `https://www.icloud.com/*` | iCloud.com의 ‘나의 이메일 가리기’ 화면 조작 |

이 확장 프로그램은 `cookies`, `tabs`, `webRequest`, `scripting`, `<all_urls>`를 요청하지 않습니다. 브라우저 보호 기능을 비활성화하지도 않습니다.

## 개인정보

- 비밀번호, 인증 코드, Cookie를 읽거나 저장하거나 전송하지 않습니다.
- 만든 주소는 확장 프로그램의 세션 저장소와 클립보드에만 둡니다. 브라우저를 다시 시작하면 `chrome.storage.session`이 지워집니다.
- 외부 서버와 통신하지 않습니다. 통신은 사용자가 연 iCloud.com 화면과 Apple 사이에서만 이루어집니다.
- 확장 프로그램 로그에 주소나 인증 정보를 출력하지 않습니다.
- 중복 생성을 막기 위해 생성 버튼을 눌렀다는 사실과 작업 상태만 세션에 남깁니다.

## 문제 해결

**‘Apple 로그인이 필요합니다’가 표시됨**<br>
팝업의 ‘iCloud 열기’를 눌러 iCloud 탭에서 로그인한 뒤 팝업으로 돌아와 다시 생성하세요.

**‘iCloud 화면을 열 수 없습니다’가 표시됨**<br>
Apple 로그인, 네트워크 연결, iCloud+ 구독 상태를 확인하세요. ‘iCloud 열기’로 화면을 확인할 수 있습니다.

**‘생성 결과를 확인하지 못했습니다’가 표시됨**<br>
중복 생성을 막기 위해 자동으로 재시도하지 않습니다. ‘iCloud에서 확인’을 열어 같은 레이블의 주소가 추가로 생기지 않았는지 확인하세요. 확인되면 확인란을 선택하고 ‘확인 완료로 표시하고 재개’를 누르세요.

**‘iCloud+ 화면을 찾지 못했습니다’가 표시됨**<br>
iCloud.com에 ‘나의 이메일 가리기’가 표시되는지 확인하세요. 표시되지 않으면 iCloud+ 구독과 웹 전용 접근 설정을 확인하세요.

**주소가 복사되지 않음**<br>
팝업의 ‘복사’를 누르세요. iCloud 탭을 앞으로 가져올 필요는 없습니다. 팝업을 닫았다면 다시 열면 결과가 표시됩니다.

## 빌드와 테스트

```bash
npm install
npm run typecheck
npm test
npm run build
npm run test:e2e
```

- `npm run check`: 타입 검사, 단위 테스트, 프로덕션 빌드를 실행합니다.
- `npm run test:e2e`: Chrome for Testing(또는 Chromium)에 확장 프로그램을 로드하고 로컬 모의 iCloud 화면에서 생성, 복사, 미로그인, 세션 만료, 생성 실패 등을 확인합니다.
- E2E에 다른 Chrome을 사용하려면 `CHROME_PATH`를 지정하세요.

```bash
CHROME_PATH="/path/to/Google Chrome for Testing" npm run test:e2e
```

`dist/`는 `npm run build`로 생성됩니다. 이 프로젝트는 서명된 릴리스 패키지나 Chrome 웹 스토어 배포를 제공하지 않습니다.
